Duplicates

The same movie or episode in more than one place (for example in both your old library and the Sonarr/Radarr one), or two versions of one movie side by side. Reclaimer suggests which copy to keep: one Sonarr/Radarr manages first (so they don't re-download it), then the highest resolution, then the biggest. Pick a different one with the radio buttons. Removed copies go to a holding folder, so nothing is deleted until you empty it on the Recommendations tab.

Scan your libraries, then come back here.

Junk

Leftovers that Plex doesn't need: sample clips, unfinished downloads, archives that were already extracted, release clutter like RARBG.txt or .exe files, and optionally stray subtitle files, extras and folders with no video left. Only the first four are ticked by default. Everything goes to the same holding folder.

Presets: how Reclaimer treats each kind of video

A preset is a recipe for one kind of video. A cartoon can shrink a lot and look the same; live sports can't. So each kind gets its own recipe.

1 · Picked for youEach show or movie gets a preset from its genres (Settings → Genre rules), or its library's default. Change any single show from the dropdown on the Recommendations tab.
2 · Tuned for the contentA preset decides the largest picture size, how hard to squeeze, and what to do with the sound and subtitles.
3 · Safe to changeChanges only affect future encodes. Try one on a single file with preview before queuing a whole show.

Audio languages

Drop audio tracks in languages nobody here listens to. Files with only one audio track, or with none of your kept languages, are never touched by this. When the video is already fine, the file is just repacked (seconds, no quality loss).

Optional but recommended. If Reclaimer shrinks an episode below the quality Sonarr is set to want (its "cutoff"), Sonarr may download the bigger copy again. With these filled in, Reclaimer never goes below a cutoff, prefers keeping the copy they manage when removing duplicates, and asks them to rescan what it changed. API key: in Sonarr/Radarr, Settings → General → Security → API Key.

Media servers

Optional; add whichever you use (any combination works). Reclaimer reads each show's and movie's genres from them to pick presets, pauses encoding while someone is watching, lists transcodes on the Health tab, and asks them to rescan after changes. Plex token: in Plex Web open any item → ⋯ → Get Info → View XML, then copy the X-Plex-Token value from that page's URL. Jellyfin / Emby: create an API key under Dashboard → API Keys. Kodi: turn on Settings → Services → Control → "Allow remote control via HTTP"; the URL is the device's address and port (usually 8080), plus the username/password set there.

Genre rules

Genres come from your NFO files and every media server above. First matching rule wins; Documentary+Crime means both genres, Reality|Game Show means either one. Manual overrides on the Recommendations tab always win. A blank preset leaves the library's default.
